# Application Workspace

This local-only workspace keeps one private package for every job the user
explicitly approves for preparation. It is intentionally separate from Career
Evidence Vault folders: nothing here is used to prove an achievement, score a job,
or update the source résumés.

## Start here

- New approved packages: `01 Active/`
- Retired or completed packages: `99 Archive/`
- Use: [[Templates/Application Package]]

## Operating rules

- A package contains the normalized JD, sourced strengths and gaps, a résumé
  tailoring brief, and an empty cover-letter section.
- Generate or save a cover letter only after a separate, job-specific user
  request and explicit approval of that letter.
- Link to verified evidence notes with Obsidian links. Generated copy is a draft,
  not evidence.
- The linked PDF in `resumes/` remains the selected source résumé. Do not edit,
  replace, or generate a résumé file here.
- This folder is excluded from `vault_evidence.py` and ignored by Git. Do not
  place application content in logs.

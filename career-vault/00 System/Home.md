# Career Evidence Vault

This vault stores structured, source-linked career evidence for truthful job
matching and application preparation.

## Review queue

- Resume-derived notes should be marked `status: verified` only after review.
- Resolve conflicts between resume versions before using the claims for scoring.
- Confirm profile, target-role preferences, and work authorization separately.
- New notes should start as `draft` or `needs-review` and be promoted only after
  confirmation.
